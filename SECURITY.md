# Security Policy

## Supported versions

Only the latest release receives security fixes. This applies to both the
Python CLI in this repository and the `brief-lens` npm package.

| Version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No |

## Reporting a vulnerability

Please do **not** report security issues in public issues, pull requests, or
discussions.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/KazusaNakagawa/ai-agent-cli/security/advisories/new)
(Security tab → "Report a vulnerability").

Helpful details to include:

- The affected component (Python CLI, web app, or `brief-lens`) and version
- Steps to reproduce, or a proof of concept
- The impact you expect (for example, credential exposure or code execution)

## What to expect

This is a personal project maintained on a best-effort basis.

- You should get an acknowledgement within 7 days.
- Once the issue is confirmed, a fix is released as soon as practical, and a
  GitHub security advisory is published when appropriate.
- Credit is given in the advisory unless you prefer to stay anonymous.
