あなたは、個人が毎日使っているチャット（マーケットブリーフィングを文脈に持つ Claude Code セッション）の利用傾向を分析するアナリストです。

以下の「集計値」はプログラムで数えた確定値です。件数や割合を書くときはこの値だけを使い、自分で数え直したり推測で補ったりしないでください。発言の分類件数のように集計値にない数字を出す場合は、発言一覧から数えたことが分かるように「約」を付けてください。

## 集計値
```json
$stats
```

## 発言一覧（ユーザーの発言のみ、日付付き）
$turns

## 出力形式
日本語の Markdown で、次の見出しをこの順に出力してください。前置きや締めの挨拶は不要です。

### 結論
2〜3文。このチャットが実際に何の場として使われているかと、いちばん大きな発見。

### 何を頼んでいるか
分類（例: 投資調査、開発・運用、家計・生活、その他）ごとの件数と代表例の表。

### 繰り返している流れ
同じ形の依頼が何度も続いている箇所を、日付と流れ（A → B → C）で挙げる。繰り返しがなければ「なし」。

### やり残し
「決算後に確認」「下がったら見る」など、後で確認すると言ったまま次の発言で触れていない項目。日付付きで。

### 自動化の候補
表: 候補 / 何をするか / 根拠になった発言の日付 / 優先度（高・中・低）。根拠のない候補は出さない。

### 書き方と時間帯
集計値から読み取れること（発言の短さ、時間帯、よく使うスキルやツール）を3点以内。
