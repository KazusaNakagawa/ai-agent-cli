brief-lens ユーザーガイド

brief-lens は、地政学イベント・株価の動き・セクターのテーマを毎朝集め、あなたのポートフォリオにとって何を意味するかまで踏み込んだブリーフィングを Claude に書かせるアプリです。 ブリーフィングを読み、質問し、気づきをジャーナルに残すところまでを、ブラウザの画面ひとつで扱えます。 

npx brief-lens
投資助言ではありません。 ブリーフィングは LLM が Web 検索の結果をもとに生成するもので、誤り・欠落・古い情報を含むことがあります。どの有価証券の売買を勧めるものでもありません。情報はご自身で確かめ、投資判断はご自身の責任で行ってください。

できること

自分の視点を登録する 保有銘柄、気になるテーマ、ウォッチするセクター、地政学リスクを登録します。ブリーフィングはこの視点で書かれます。 ブリーフィングを生成する ボタンひとつで当日のブリーフィングを作ります。Claude Code の WebSearch で最新のニュースを調べます。 読んで、探す 過去のブリーフィングと週次リキャップを一覧し、ファイル名や本文で検索して目次付きで読めます。 ブリーフィングに質問する 本文を横に表示したまま質問できます。回答は Notion のブリーフィングページにも追記できます。 ジャーナルに残す その日の出来事や考えを書き留め、ためたジャーナルをもとに Claude とブレインストーミングできます。 コストを把握する Claude Code の利用量を API 換算のコストで、日別・モデル別・プロジェクト別に確認できます。

必要なもの

  • macOS または Linux（Windows には対応していません）
  • Node.js 18 以上と uv
  • ログイン済みの Claude Code CLI と、有料の Claude プラン（Pro / Max）。アプリは CLI のログインセッションを使って Claude を呼び出すため、無料プランでは動きません

Discord や Notion への配信は任意です。使う場合だけ、あとから認証情報を登録します。

はじめ方

  1. インストールと初回セットアップで、npx brief-lens を実行してセットアップウィザードを終えます。
  2. 画面の基本で、画面の構成とデータの保存場所を確認します。
  3. 視点を設定するで銘柄やテーマを登録し、Run から最初のブリーフィングを生成します。
リポジトリを clone して使う場合 毎朝の自動実行や、Discord・Notion への定期配信、CLI のコマンド群を使うときは、ソースからのセットアップが必要です。ソースから使う・毎日の運用を参照してください。

名前について

npm で配布しているパッケージ名が brief-lens、リポジトリ名が ai-agent-cli（プロジェクト名 My World Briefing）です。 アプリの画面左上には ai-agent と表示されます。どれも同じアプリを指しています。
