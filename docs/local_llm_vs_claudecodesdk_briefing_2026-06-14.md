## 1. サマリー

ローカル LLM 版は、6/13 のレビュー（`local_llm_briefing_review.md`、評価「モデル性能 30% / ワークフロー 70%」）に基づく
PR1〜5（ソースノイズ除去・因果3行・地政学チャネル絞り込み・セクター層・PM視点示唆）を反映し、
**データ取得・URL検証・構造面では Claude Code SDK 版に肉薄**するところまで到達した。

一方で **内容の論理整合性・ナラティブの深さ・因果の正確さでは依然として明確な差**が残る。
反復の終盤では「藪蛇でキリがない」とプロンプト調整の限界に達し、中国系モデルを全削除して
`gemma2:9b` に切り替えたが、構造的な品質ギャップは埋まっていない。

**結論: 構造・検証はワークフローで詰められたが、ナラティブ品質はモデル性能に律速される。**

## 3. 定性比較

### Claude Code SDK 版の強み
- **重層ナラティブ**: 「世界マクロ → セクター → 個別銘柄 → 示唆」が因果でつながり、SpaceX IPO・イラン戦争・FRB新体制・米中貿易を 1 つのストーリーに統合。
- **因果の正確さ**: DXCM 上昇＝CONNECT/投資家説明会、NOC＝決算・配当・PT 改定など、値動きと理由が正しく対応。
- **網羅性**: 16 セクターの動向を個別に解説。保有外銘柄まで横断的にカバー。

### ローカル LLM 版の強み
- **検証の機械的担保**: 捏造 URL を `<URL未検証>` へ機械置換。Sonnet 版が持たない「構造的な捏造防止」。
- **pre-fetch の透明性**: Brave hits 件数・取得率・debug raw を出力に明示。再現性・監査性が高い。
- **PR1〜5 の効果が可視化**: 因果3行・セクター層・PM視点示唆（買い増し/注意/監視）の構造は導入済み。

### ローカル LLM 版に残る問題点（007 の最終評価より）
1. **ヘルスケアのDXCM記述が誤り（L42-44）**: 「イラン情勢緩和で反発 → DXCM」と紐付けているが、DXCM の上昇要因は CONNECT 試験陽性結果（L98）。セクション間のコピペ的混線。
2. **CBRS 株価 $214.00 の根拠不明**: Brave hits = 0、ニュースなしにもかかわらず `↓6.7% ($214.00)` が記載。データ出所が追えない。
3. **監視イベントの陳腐化**: SpaceX IPO を「6月12日に上場予定」と記載。6/14 時点で既に上場済みのはずで「予定」表現が不正確（Sonnet 版は「初日 +19%」と現在進行を反映）。
4. **地政学→銘柄の波及が紋切り型**: 「○○情勢の不安定化 → エネルギー価格 → NOC」が複数トピックで使い回され、固有性が薄い。

## 5. 結論と次アクション

- **ワークフロー（70%）の改善は機能した**: ソースノイズ除去・URL 検証・構造化・セクター層は Sonnet 版に近い形まで到達。
- **モデル性能（30%）に律速される領域が残る**: セクション間の因果整合、値動きと理由の正しい対応、ナラティブの固有性は `gemma2:9b` では限界。
- **優先修正候補**:
  1. ヘルスケアセクションの DXCM 説明（セクション間のコンテキスト混線対策）
  2. CBRS のように Brave hits=0 の銘柄で値動き記述が出る経路の確認
  3. 監視イベントの日付鮮度フィルタ（「予定」表現の陳腐化防止）
- **defer 済みエピック**（別 Issue）: ニュースのクラスタリング / 重要度スコアリング / 最終段だけ別推論モデル（Qwen 32B / DeepSeek R1）。
  ナラティブ品質の本質的改善はこの「最終段の高性能モデル投入」に依存する見込み。
