困ったときは

よくある症状と対処法をまとめています。ここで解決しないときは、GitHub の Issues で報告してください。セキュリティに関わる問題は、公開の Issue ではなく非公開の脆弱性報告からお願いします。

起動

症状原因と対処
missing prerequisites と出て終了する一覧に出た不足分（Node.js、uv、claude）を入れてから、もう一度実行してください。
port 8000 is already in useほかのサーバー（clone した環境の bin/serve.sh など）がポートを使っています。--api-port / --port で別のポートを指定してください。
初回の「Installing Python dependencies」から進まないuv がパッケージをダウンロードしています。キャッシュが空だと数分かかります。
初回のインストール中に Ctrl + C で止めてしまった問題ありません。次に起動したときにインストールをやり直します。
session-token is a symlinkランチャーはシンボリックリンク越しにトークンを書きません。リンクを削除してから起動してください。

画面の表示

症状原因と対処
「briefing.json is missing」と表示される設定ファイルがありません。Config → Setup でセットアップウィザードをやり直してください。
「Session expired」と表示される（clone した環境）Web UI と API のトークンが食い違っています。bin/serve.sh を起動し直してから、ページを再読み込みしてください。
Workspace でフォルダーを開けないChrome か Edge で開いてください。Safari や Firefox には、Workspace が使うファイルアクセスの API がありません。
Monitor と Usage の数字が合わない仕様です。Monitor は Claude Code 全体、Usage は brief-lens の実行分だけを数えています（Monitor と Usage）。

ブリーフィングの生成

症状原因と対処
Run の Status が failed になる表示されるエラーを確認してください。多くは設定ファイルの不整合か、認証情報の不足です。先に Dry run で認証情報を確かめると切り分けられます。
生成の進みが止まって見えるWeb 検索の応答を待っていることがほとんどです。途中で止めると、それまでの利用枠を使ったうえでやり直しになるので、しばらく待ってください。
本文に「セクター調査に失敗」のような注記がある一部の生成が失敗し、残りの部分で配信しました（デグレードモード）。clone した環境では bin/recover.sh で欠けた部分を補えます。
毎朝の自動実行で何も生成されず、利用枠だけ減るMac がスリープしていた可能性が高いです。蓋を開けて AC 電源につないでおくか、手動実行に切り替えてください（毎朝自動で実行する）。

チャットと Journal

症状原因と対処
過去ブリーフィングを検索 を入れるとエラーになるこの機能はローカル LLM（Ollama + Chroma）の索引を使います。Ollama が動いていないか、索引がまだありません。チェックを外せば通常どおり質問できます。
Journal で「No journal entries yet — record something first.」と出る直近のジャーナルが 1 件もありません。Journal の注意を参照してください。
Notion への追記が 追記を再試行 になるNotion の認証情報か、Claude Code の /notion-import スキルを確認してください。ローカルの Markdown への追記は別に行われています。

Notion が 401（Unauthorized）を返す

  1. キーチェーンに古い値が残っていないかを確認します。キーチェーンの値は .env より優先されるので、.env だけ直しても反映されません。Config → Credentials で登録し直してください。
  2. Notion の インテグレーションの設定で、トークンが正しいかを確認します。
  3. トークンが正しいのに 401 が続く場合は、インテグレーションが対象のデータベースに接続されていない可能性があります。Notion でデータベースを開き、… → 接続（Add connections）からインテグレーションを追加してください。
