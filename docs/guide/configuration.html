設定ファイル

ブリーフィングの対象は、すべて briefing.json で決まります。コードを変えずに、銘柄・セクター・地政学リスク・為替などを差し替えられます。画面から編集できるのは一部の項目だけで、残りはこのファイルを直接編集します。

ファイルの場所

使い方場所
npx 版~/.brief-lens/config/briefing.json
clone した環境apps/python/config/briefing.json（Git の管理外）

テンプレートはリポジトリの briefing.json.example です。編集は、テキストエディタで直接行うか、Config → Config file で書き出して読み込み直します。保存した内容は次の実行から使われます。

briefing.json の項目

キー内容画面
portfoliotickers（銘柄コード）と themes（テーマ）Portfolio
watch_sectorsセクターごとの sector・tickers・notes。1 つ以上必要Watch Sectors
geopolitical.conflicts地政学リスクごとの name・affected_sectors・related_tickers・notesGeopolitical Risks
watch_events起きたら影響が大きいイベント。name・trigger（何が起きたら注目するか）・affected_sectors・related_tickers・notes—
fx為替。pairs（通貨ペアと注意する水準 band_low / band_high）、usd_asset_share（ドル建て資産の割合 0〜1）、scenario_rates（影響を試算するドル円の水準）。pairs が空なら為替の項目は出ません—
modelClaude Code CLI に渡すモデル—
fallback_modelメインのモデルが混雑・利用不可のときに切り替えるモデル（カンマ区切りで複数可）—
obsidianObsidian の Vault との連携（ジャーナルの書き出しなど）。vault_path・journal_subdir・exclude_dirs—
journal_chatジャーナルのブレインストーミングで、Claude にファイルの書き込みを許すフォルダー（trusted_write_dirs）—
speech読み上げ用の原稿。audio を true にすると macOS の say で音声ファイルも作る。voice・max_chars—
slidesスライド（Marp）の設定。max_claims は 1 枚に載せる論点の数—

最小の例

{
  "portfolio": {
    "tickers": ["AAPL", "MSFT"],
    "themes": ["AI規制", "金融政策"]
  },
  "watch_sectors": [
    { "sector": "AI・クラウド", "tickers": ["MSFT", "AMZN", "GOOGL"], "notes": "設備投資の動向" }
  ],
  "geopolitical": {
    "conflicts": [
      {
        "name": "米中の技術規制",
        "affected_sectors": ["半導体"],
        "related_tickers": ["TSM"],
        "notes": "輸出管理の対象拡大に注目"
      }
    ]
  }
}

銘柄は説明用の例です。

環境変数

clone した環境ではリポジトリ直下の .env、npx 版では ~/.brief-lens/.env に書きます。

変数用途
DISCORD_TOKEN / CHANNEL_IDDiscord への配信
NOTION_API_KEY / NOTION_DATABASE_IDNotion への配信とチャットの追記
NOTION_DATABASE_ID_JOURNALジャーナルの Notion 同期
ANTHROPIC_API_KEYAPI モードのときだけ使う。CLI モードでは子プロセスに渡さない
CLAUDE_MODELmodel より優先して使うモデル
CLAUDE_FALLBACK_MODELfallback_model より優先する切り替え先のモデル
BRAVE_API_KEYローカル LLM モードの Web 検索
RCLONE_REMOTEアーカイブのアップロード先（rclone のリモート名）

認証情報の優先順位

Discord・Notion・Anthropic の認証情報は、OS のキーチェーン → .env の順に探します。キーチェーンに値があると、.env を書き換えても反映されません。値を変えたいときは、Config → Credentials で登録し直してください。

そのほかの設定ファイル（clone した環境）

ファイル用途
config/holdings.jsonbin/portfolio.sh が読む保有ポジション
config/money_rules.jsonbin/money.sh が使う取引の分類・振替ルール
config/self_agent_profile.mdbin/self_agent.sh が更新するペルソナのプロファイル
apps/python/prompts/briefing_*.mdブリーフィングのプロンプトのテンプレート（本文・保有銘柄・セクターなど、セクションごとに分かれています）

個人のデータを含むファイルは Git にコミットしません。リポジトリには、形式を示す .example だけがあります。
